========================================
酒帖 — まとめて更新するための手順
========================================

【1】ファイルをGitHubに入れる

  1. GitHub Desktop で Current repository を「sake」にする
  2. メニューの Repository →「Show in Explorer」でフォルダを開く
  3. このフォルダにある次の6つを、そこへコピーして上書きする

       index.html
       sw.js
       icon-192.png
       icon-512.png
       apple-touch-icon.png
       favicon-32.png

  4. GitHub Desktop に戻ると変更が一覧に出る
  5. 左下の Summary に update と入力 →「Commit to main」
  6. 上部の「Push origin」を押す


【2】SupabaseでSQLを実行する（まだの場合のみ）

  1. supabase.com → プロジェクト sakecho
  2. 左メニュー「SQL Editor」→「New query」
  3. supabase-schema.sql の全文を貼り付け → Run

  ※すでに実行済みなら飛ばして構いません。
    再実行してもデータは消えません。


【3】オフラインで使えるようにする

  1. オンラインの状態で https://yuki-washoku.github.io/sake/ を開く
  2. Ctrl+Shift+R で再読み込み（iPhoneはタブを閉じて開き直す）
  3. ログインして、在庫画面を一度開く
     ← ここで端末に控えが保存されます
  4. ホーム画面に追加する
  5. 機内モードにしてアイコンから起動 → 開けば成功

  ※新しいスタッフの端末も、必ず一度オンラインで
    ログインしておいてください。


----------------------------------------
オフラインでできること
----------------------------------------
・アプリの起動と182銘柄の検索、絞り込み
・在庫数の増減
・メモ、保管場所、仕入値、売価、発注点の記入
・写真の撮影と添付
・銘柄の手入力での追加

  変更は端末に貯まり、画面上部に「未送信 ○件」と出ます。
  電波が戻ると自動で送信され、表示が消えます。

----------------------------------------
オフラインでできないこと
----------------------------------------
・招待リンクの発行
・メンバーの権限変更
・アカウントの追加、名称変更
・履歴の表示と復元
・アカウント間の移動
・写真の文字読み取り（初回の辞書取得のみ通信が必要）


----------------------------------------
困ったときは
----------------------------------------
・オフラインでログイン画面が出る
    → 一度オンラインでログインし、在庫画面を開いてから
      もう一度お試しください。
      それでも出る場合は、画面の
      「通信せずに前回の内容を開く」を押してください。

・オフラインで真っ白／開かない
    → sw.js がGitHubに入っているか確認してください。

・招待リンクが発行できない
    → 【2】のSQLを実行し直してください。

・アイコンが古いまま
    → ホーム画面のアイコンを削除し、
      Safariで開き直して追加し直してください。

・SQL実行で赤いエラーが出た
    → エラー文をそのままClaudeに送ってください。
