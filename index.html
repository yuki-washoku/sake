銘柄を追加

追加した銘柄はこの端末のブラウザに保存されます。機種変更やアプリ再インストールに備えて、ときどき「書き出し」でバックアップしてください。

写真から追加

写真の文字を入れる方法（どちらも無料）

1. 端末の文字認識を使う
iPhone：写真アプリで画像を開き、右下の文字認識アイコンをタップ → 文字を長押しで全選択 → コピー → 上の欄に貼り付け。
Android：Googleフォトの「レンズ」→ テキストを選択 → コピー。

2. このチャットに写真を送る
Claudeに画像を送れば、名称・種別・精米歩合・日本酒度・産地・酒造を読み取ってJSONで返します。それを上の欄に貼り付ければそのまま登録できます。追加料金はかかりません。

収録済みの銘柄名が写真の文字に含まれていれば、精米歩合や産地などは自動で補完されます。

ホーム画面／デスクトップに追加

iPhone・iPad（Safari）

  1. このファイル（sake.html）を iCloud Drive や Google ドライブなどに置き、Safari で開く
  2. 画面下の共有ボタン（□に↑）をタップ
  3. 「ホーム画面に追加」を選び、名前を「酒帖」にして追加

Android（Chrome）

  1. Chrome でこのページを開く
  2. 右上の︙メニューをタップ
  3. 「ホーム画面に追加」を選ぶ

パソコン（Windows／Mac）

  1. sake.html をデスクトップに保存する（それだけでダブルクリックで開けます）
  2. 常用するなら Chrome / Edge で開き、︙ →「保存して共有」→「ショートカットを作成」→「ウィンドウとして開く」にチェック
  3. 作られたアイコンをデスクトップに置けば、アプリのように単独ウィンドウで起動します

ネット接続なしでも動きます（フォントだけオンライン時に切り替わります）。iPhone でファイル保存だけではホーム画面に追加できないため、クラウド等の URL で開くのが確実です。
